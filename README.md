# RCTGames website

The public developer website for RCTGames, served by GitHub Pages at https://bostonredsoxrules-star.github.io

- `index.html` is the page people see.
- `app-ads.txt` tells ad networks who is allowed to sell ads in the games. Google AdMob reads it from the root of
  this site to verify each game, so keep the file name and its line exactly as AdMob gives them
  (AdMob > Apps > Set up app-ads.txt).
- `.nojekyll` makes GitHub serve the files as they are.

To change the site, edit the files and push to `main`; the page updates in a minute or two.
